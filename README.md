# Signal vs. Noise — Daily Dopa Sensory & Attention Audit

A minimalist, design-forward interactive web app that bridges neuroscience, sensory perception, and digital habits. Users take a quick 3-minute audit to discover their sensory archetype and receive a personalized dopamine-management prescription.

## 🌿 Overview
* **Brand:** Daily Dopa
* **Focus:** Dopamine, attention, intention, and the 5 senses (plus intuition and digital feeds).
* **Aesthetic:** Organic monochrome, warm cream tones, glassmorphism card touches, and ultra-clean typography.

## 🚀 Live Preview
You can view the live, fully interactive web app here:  
👉 [https://antoinettevandewark.github.io/Signal-vs-Noise/](https://antoinettevandewark.github.io/Signal-vs-Noise/)  

## ✨ Features
* **Gated Entry & Compliance:** Secure email capture with explicit marketing consent handling for clean list building.
* **Rapid Assessment:** Multi-step audit mapping answers to 10 distinct sensory archetypes (from *The Tactile Purist* to *The Sonic Architect*).
* **Actionable Prescriptions:** Every archetype comes paired with a precise "Try This Today" micro-experiment and behavioral rationale.
* **Fully Responsive:** Built with vanilla HTML, CSS, and JavaScript for lightning-fast loading speeds and zero bloat.

## 🛠️ Tech Stack
* **HTML5 / CSS3** (Custom glassmorphism styling & fluid layouts)
* **JavaScript (ES6+)** (Dynamic state management and scoring logic)
* **Hosted on:** GitHub Pages
